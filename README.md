## 📌 Tentang Proyek / About the Project

**[ID]** Proyek ini adalah antarmuka pengguna (User Interface) berbasis web statis untuk platform edukasi *coding* "Ngoding Bareng". Dibangun menggunakan framework **Bootstrap 5**, halaman ini dirancang untuk menampilkan profil komunitas, layanan belajar, pameran portofolio proyek, serta halaman FAQ. Fokus utama proyek ini adalah desain yang sangat responsif dengan sentuhan animasi modern.

**[EN]** *This project is a static web-based User Interface for a coding education platform called "Ngoding Bareng". Built with the **Bootstrap 5** framework, this landing page is designed to showcase the community profile, learning services, project portfolios, and an FAQ section. The main focus of this project is a highly responsive design with modern animation touches.*

---

## 🚀 Fitur Utama / Key Features

**[ID]**
* **Desain Responsif (Bootstrap 5):** Tata letak yang beradaptasi sempurna di berbagai ukuran layar (Desktop, Tablet, dan Mobile) menggunakan *Grid System* dari Bootstrap.
* **Animasi Interaktif (AOS & Animate.css):** Elemen visual (teks, gambar, kartu) akan muncul dengan animasi transisi yang halus saat pengguna melakukan *scroll* ke bawah.
* **Komponen Interaktif:** Dilengkapi dengan *Collapsible Navbar* untuk tampilan mobile dan menu FAQ bergaya *Accordion* (buka-tutup) yang menghemat ruang halaman.
* **Pameran Portofolio:** Terdapat seksi khusus untuk menampilkan proyek web dengan tautan langsung menuju *Source Code* (GitHub) dan *Live Website*.

**[EN]**
* **Responsive Design (Bootstrap 5):** Layouts that adapt perfectly across all screen sizes (Desktop, Tablet, and Mobile) using Bootstrap's Grid System.
* **Interactive Animations (AOS & Animate.css):** Visual elements (texts, images, cards) appear with smooth transition animations as the user scrolls down the page.
* **Interactive Components:** Features a Collapsible Navbar for mobile views and an Accordion-style FAQ menu to save page space.
* **Portfolio Showcase:** A dedicated section to display web projects with direct links to the Source Code (GitHub) and Live Websites.
